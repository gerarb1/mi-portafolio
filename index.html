    ERP Avícola — Detalles Arquitectónicos

    Enfoque del Proyecto: Desarrollo de lógica de negocio en backend con Node.js y diseño de base de datos SQL para el control operacional de granjas avícolas.

    Aspectos Clave:

    • Gestión de Inventarios & Alimento: Algoritmos de cálculo automático de insumos requeridos según la población de aves.
    • Base de Datos Relacional SQL: Normalización de tablas para la trazabilidad de lotes, tasas de mortalidad, vacunación y peso medio.
    • Reportes y Métricas: Consultas agregadas y vistas SQL para generación de gráficos de rendimiento económico y productivo.

    Chocolates Para Ti Mobile App — Detalles

    Enfoque del Proyecto: Aplicación orientada a mejorar las ventas y la interacción del cliente final para la emblemática marca de chocolates.

    Aspectos Clave:

    • Interfaz Ágil en React: Catálogo de productos interactivo ordenado por categorías, ofertas y momentos especiales.
    • Carrito & Pedidos: Gestión del estado local del pedido y envío de orden hacia la API backend en Node.js.
    • Diseño Adaptativo: Estilizado limpio con Tailwind CSS optimizado para pantallas táctiles de teléfonos inteligentes.

    TaskNote CI/CD Pipeline — Detalles

    Enfoque del Proyecto: Demostración práctica de automatización DevOps utilizando GitHub Actions para la integración y despliegue continuo.

    Aspectos Clave:

    • Pruebas Automatizadas: Configuración del script `npm test` ejecutado automáticamente en cada push a la rama principal.
    • GitHub Pages Deployment: Despliegue automático de artefactos estáticos sin necesidad de intervención manual.
